# Repository Instructions

## Purpose

This repository contains my graduate-school research and technical
learning notes.

My current research focuses on heterogeneous quantum-classical
computing and compiler toolchains, including XACC, QCOR, and CUDA-Q.

Long-term technical interests also include:
- compiler infrastructure
- LLVM / MLIR
- CUDA
- HPC
- computer architecture

## Repository Organization

- `quantum-computing/`: quantum computing research and experiments
- `compiler/`: compiler, LLVM, MLIR, and related notes
- `cuda-hpc/`: CUDA and HPC notes
- `computer-architecture/`: computer architecture notes

Do not create new top-level directories unless there is a clear need.

## Markdown

- Markdown is the primary documentation format.
- Keep notes readable in both VS Code and GitHub.
- Do not unnecessarily rewrite my personal notes.
- Preserve my original wording unless I explicitly request editing.
- Prefer relative links between documents.

## Research Notes

These are learning notes, not polished publications.

Do not silently correct uncertain technical claims.
If something appears technically incorrect, point it out instead of
rewriting it as if it were established fact.
